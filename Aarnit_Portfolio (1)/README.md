# Aarnit Prashant Nair — Portfolio

Responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Create a public repository named `Aarnit2005.github.io`.
2. Upload `index.html` and `aarnit-profile-photo.jpg` to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`.
5. Your portfolio should publish at `https://Aarnit2005.github.io/`.

## Notes
- The Projects section loads public repositories from the GitHub API.
- The website includes relevant professional, education, project, internship, leadership, certification and achievement information.
- No resume file is included or offered for download.
- Review contact details before publishing publicly.
